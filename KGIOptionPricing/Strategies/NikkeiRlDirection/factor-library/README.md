## 使用方式

因子庫入口為本檔與 research-library.json。更新使用 scripts/research/import_factor_library.py（bundled Python），指定 --workbook 與 --output，並用 --screening-report 保留篩選證據。
Python研究程式可用本匯入模組的 select_candidates(registry, [51, 52]) 明確取得定義。C#可用 System.Text.Json 讀取 candidates 陣列；本檔不是交易模型。
原50因子的既有資料限制保留。51–61的研究實作狀態詳表，均未接入60維模型；工程版本通過預測篩選後，仍需RL實際回測與C#一致性驗證。
