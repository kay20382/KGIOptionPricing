# 多因子均價回歸 R17

來源：已封存研究 `round17/mean_mini_return_minus05_score025`，新增獨立策略類型 `MultiFactorMeanR17`。交易225MC一口，225M及225為參考商品；透過共用StrategyHost、訂單、績效帳本和實盤歸屬路由。

模擬及實盤策略中心各新增一個頁籤。預設等使用者按啟動；實盤仍需勾選確認、登入、商品解析與單日虧損上限。建立表單／策略不送單。

## 訊號與出場

有效微型成交才可觸發進場。指標使用接收時間；單筆口數10倍數不進入力道或行情段，不觸發決策。參考商品的原始正口數成交強度仍遵循R17定義。

每個實例各自維護FactorState。30..60個連續已完成秒的微型中價均值減最新已完成秒中價，再除以5，得到均價偏離跳数。缺秒、不新鮮或不足樣本不插補。

- 均價偏離絕對值>=0.25跳，正值買進、負值賣出。
- 方向×兩商品力道平均/100>=-0.2；方向×平均第一檔佇列不平衡>=-0.3。
- 方向×225M最新已完成秒報酬>=-0.5跳。
- 方向×(1−2×大型30秒下行變異占比)>=-0.1；大型成交強度>=0.3筆/秒。
- 固定30秒RMS跳動波動×sqrt(30)×2，向上取整，停損4..30跳；停利跳數為停損×1.5向上取整，上限60跳。停損触發距離最高150點，成交損失不裁切。
- 成交後以實際成交價固定原規劃幾何。移動出場0.8R啟動／0.5R回撤；原力道反向持續30秒或持倉180秒可出場；冷卻20秒。
- 第一檔交叉委託量加權中價比較：微型>大型，買進掛買一／賣出市價；否則買進市價／賣出掛賣一。掛單等待10秒後撤單並待確認。

所有生效值在頁籤、快照及共用manifest中揭露。修改畫面参数不修改運作中實例；先空手關閉，再新建實例暖機。變更設定後不引用原六日結果。

## 研究限制

原六日合計683筆，淨勝率48.61%，毛損益27,200JPY，淨損益-21,976JPY，毛期望39.82JPY／筆、淨期望-32.18JPY／筆，只有3／6日符合研究門檻。這是歷史研究證據，整合與合成冒煙測試不等於再次通過多日、樣本外或券商實盤驗證。未自動啟動實盤。

## 可觀測性與分析

共用紀錄包含健康條件、R17.ScoreMagnitude、SignedQueue、SignedPower、MiniSignedCompletedReturn、LargeSignedVariancePressure、LargePrintRate及報酬風險門檻。UI顯示三商品因子、部位、來回數、交易口數、毛／淨損益、淨期望、勝率、平均獲利／損失點數與獲利因子。

分析入口：`python -B analysis/analyze_multifactor_mean_r17.py --runs <共用產物資料夾> --output <分析輸出資料夾> --mode all`。沿用既有PowerReversal分析讀檔與驗證工具，另驗證R17參數／150點停損上限；只輸出JSON／Markdown報告，不更新設定、不回測、不下單。

測試：`dotnet run --project tests/MultiFactorMeanR17SmokeTests`；Python：`python -B -m unittest discover -s KGIOptionPricing/Strategies/MultiFactorMeanR17/analysis`。
