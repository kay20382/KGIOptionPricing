# TXO 價平價外 IV Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以 MSSQL TXO 日盤結算價計算週三、週五與月選的價平合成期貨／最近價外 Call、Put IV，並寫入可稽核資料表。

**Architecture:** `scripts/txo_otm_iv.py` 保持為不依賴資料庫的數學與選約核心；`scripts/calculate_txo_otm_iv.py` 以既有 `sqlcmd -E -C -S .\SQLEXPRESS` 讀寫 MSSQL。假日檔是唯一的休市判定來源，報表讀取僅取三種契約中最近到期的一筆。

**Tech Stack:** Python 3.12 standard library、`unittest`、SQL Server、sqlcmd、Black-76 二分法。

**Spec:** `docs/superpowers/specs/2026-09-21-txo-atm-iv-design.md`

## Global Constraints

- 行情與 OI 只讀 `CodexMarketData.dbo`；資料庫寫入僅限新表 `dbo.TAIFEX_AtmOTMIV`。
- Call／Put 一律使用 TAIFEX `結算價`；`r=0`、`q=0`、剩餘交易日／252。
- 合約分類必須使用官方到期月份（週別）與到期日；月選不得由星期幾推測。
- OTM 定義：Call `K>F`、Put `K<F`，兩者取最接近 `F` 的有效履約價。
- 假日檔年度缺漏、無有效配對或無法收斂時必須拒算，不得回退至 ATM／ITM／舊值。
- 不新增第三方 Python 依賴。

## Review Focus

- 年度假日檔未涵蓋到期日：必須拒算並保留原因。
- 月選與週三週選同為週三：必須依 `到期月份(週別)` 正確分組。
- 平價履約價恰等於合成期貨：不得被當作 OTM。
- Call 或 Put 任一側結算價無效：另一側也不可冒充完整合約 IV。
- 資料庫 upsert：只允許覆寫同一交易日與合約類型。
