# TXO 價平隱含波動率與題材證據整合設計

## 目標與範圍

為台股盤後流程補上最近到期 TXO 的價平買權／賣權隱含波動率（IV），以 MSSQL `CodexMarketData` 為唯一行情資料來源；同時使題材篩選讀取既有的台股題材分類映射，並對網路新聞執行嚴格的 24 小時時效稽核。

本次不調整報告寄送時程、不新增夜盤選擇權分析、不擴大法人至上櫃市場，亦不寫入或改動題材分類專案的任何資料。

## 資料契約

輸入僅限本機 MSSQL：

- `dbo.TAIFEX_OptionDaily`：TXO 一般交易時段、最近到期日、同履約價的 Call／Put、結算價、未沖銷契約量。
- `dbo.TAIFEX_VIX`：保留官方 VIX；不以自行計算結果取代。
- `dbo.TAIFEX_PutCallRatio`：保留官方合併週選與月選 P/C 口徑。
- `dbo.TWSE_Daily`、`dbo.OTC_Daily`：全市場個股漲跌與成交資料，用於題材廣度計算。

題材映射唯讀取 `E:\Codex台股題材分類\題材列表.csv` 的一階題材、二階細分題材與對應股票。映射未覆蓋的股票不會被自動歸入題材。

## IV 計算

新增獨立 Python 模組與命令列入口，放在 `E:\PROG\C#\KGIOptionPricing\scripts`。輸入為交易日；預設取資料庫可核實的交易日並以半開區間查詢。

1. 只取最近契約到期日的 TXO 一般交易時段資料。
2. 同一履約價必須同時存在 Call、Put，且兩者結算價為正值可解析數字。
3. 每個配對履約價計算合成期貨 `F = K + C - P`；選取 `abs(C - P)` 最小者作為價平組合。若並列，選取履約價較低者，維持決定性結果。
4. 年化時間 `T = 剩餘交易日 / 252`；剩餘交易日定義為交易日翌日起至契約到期日（含）之臺灣市場交易日。交易日清單以可核實的實際交易日資料建立；若缺少未來交易日曆，程式必須拒算並回傳明確狀態，不得將週一至週五直接當成交易日。
5. 使用 Black-76，以 `F` 為標的、`r = 0`、`q = 0`，分別用 Call 與 Put 的結算價以有界二分法反解 IV。輸出為百分比數值。
6. 輸入價格違反無套利界限、沒有有效配對、`T <= 0`、未收斂或缺少交易日曆時，買權／賣權 IV 均留空並記錄具體原因。

輸出與既有 `選擇權波動率.csv` 對齊：填入「取樣履約價、買權IV、買權IV日變化、賣權IV、賣權IV日變化、隱波口徑」。口徑固定描述為「TXO最近到期價平合成期貨；Call/Put結算價；Black-76；r=0、q=0、剩餘交易日/252」。前日欄位只在兩日皆有效時才計算。

## 題材與新聞流程

1. 先從 MSSQL 讀取全市場個股每日漲跌與成交資料，再以唯讀題材映射做一階／二階彙總。
2. 題材排序使用映射成員的上／下漲家數、漲跌幅與成交金額；選擇可呈現廣度的主題，避免由單一股票觸發。
3. 每個選定題材至多搭配兩檔代表股，價格與漲跌幅仍以 MSSQL 為唯一數字來源。
4. 網路新聞只作背景說明。必須開啟原文，發布或實質更新時間位於執行前 24 小時內，並保存標題、媒體、時間、URL、題材與使用決策。
5. 沒有可驗證時間、重刊、論壇、社群貼文、匿名傳聞與 AI 彙整頁一律排除；合作傳聞必須標明未獲公司正式揭露。

## 失敗處理與可稽核性

- MSSQL `ImportRuns` 未顯示所需資料集完成、當日資料不完整或資料日不符時，停止該部分輸出。
- IV 缺值不以 VIX 或其他履約價替代；VIX、P/C 與 IV 為獨立欄位。
- 新聞查核失敗時，可保留純市場資料題材彙總，但不得將未經驗證的新聞原因寫入報告。
- 腳本輸出結構化狀態、資料日期、來源資料列數、選取履約價、合成期貨、剩餘交易日與拒算原因；不輸出連線憑證。

## 測試策略

先建立純函式單元測試並確認失敗，再實作：

1. 已知 Black-76 Call／Put 價格可回推出原始 IV。
2. 多履約價資料只選取 `abs(C-P)` 最小的有效配對；並列採較低履約價。
3. 缺少一方、結算價無效、違反價格界限、到期或無交易日曆時拒算且不產生 IV。
4. 剩餘交易日跨週末、跨交易所休市日與到期日的計數正確。
5. 前一交易日有效 IV 才計算日變化；任一側缺值則日變化留空。
6. 題材映射讀取不寫回，未映射股票被標示為未分類；新聞 24 小時邊界及無時間來源均被排除。

整合測試使用固定的 MSSQL 查詢結果 fixture，不連接生產資料庫；命令列整合測試驗證 CSV 欄位與稽核狀態。完成後執行新增測試與既有 Python 相關測試。

## 驗收條件

- 報告可使用最近到期 TXO 的獨立 Call／Put IV，且每個數值均可追溯到結算價、履約價、合成期貨與交易日計數。
- 所有行情數字來自 MSSQL；所有新聞均有近 24 小時的原始頁時戳與連結。
- 題材分類只讀取指定專案，不修改其 CSV、工作簿、登錄檔或備份。
- 資料不足時停止或留空並說明，絕不使用週末近似、舊 IV 或臆測數值。
